# VPT Pad — YouTube Control (розширення для Chrome / Edge)

Керує YouTube з макропада VPT | Pad. Програма VPT | Pad передає команди розширенню
через `ws://localhost:8765`, а розширення виконує їх у **одній** вкладці й повідомляє
результат назад — програма показує його в OSD (назва відео, позиція, гучність, швидкість).

## Встановлення / оновлення

1. Скопіюйте цю теку (`extension/`) на комп'ютер, напр. замініть нею вміст
   `C:\Users\admin\Desktop\VPT_Pad_Extension`.
2. Відкрийте `chrome://extensions` (в Edge — `edge://extensions`), увімкніть **Режим розробника**.
3. Старе розширення **видаліть**, потім **Завантажити розпаковане** → оберіть цю теку.
   Якщо оновлюєте ту саму теку — достатньо натиснути ⟳ на картці розширення.
4. Запустіть VPT | Pad: значок розширення без червоного «!» означає, що зв'язок є.

## Якою вкладкою керує

Команда завжди виконується лише в одній вкладці (раніше пауза ставилась у всіх одразу):

1. вкладка, закріплена вручну у вікні розширення (клік по значку);
2. вкладка, що зараз звучить;
3. вкладка, якою керували останньою — тож «пауза → продовжити» влучає в те саме відео;
4. активна вкладка з відео у вікні, яке у фокусі;
5. інші вкладки з відео (спершу ті, де ви були нещодавно).

Вкладки без відео (головна, пошук) пропускаються. Якщо розширення стоїть у кількох
браузерах, команду отримує той, де YouTube грав останнім.

## Дії

| Кнопки | Крутилка (енкодер) |
|---|---|
| Play / Pause, Назад / Вперед (1–10 с), Попереднє / Наступне відео, На початок | Перемотка (з прискоренням) |
| Гучність − / +, Звук вкл / викл | Гучність плеєра |
| Швидкість − / + / 1×, Субтитри, Режим кінотеатру, Лайк | Швидкість |

Працює на `youtube.com` (звичайні відео, Shorts, трансляції) та `music.youtube.com`.
«Попереднє відео» поводиться як у плеєрах: якщо відео грає довше 5 с — спершу на початок.

## Як влаштовано

* `background.js` — service worker: WebSocket з програмою, вибір вкладки, виконання команд.
* `targeting.js` — розбір команд і вибір вкладки (чисті функції, покриті тестами).
* `page.js` — код, що виконується на сторінці YouTube через API плеєра (`#movie_player`).
* `popup.*` — вікно розширення: стан підключення і вибір вкладки.

Розширенню потрібні лише доступ до `youtube.com` / `music.youtube.com` та `scripting`, `storage`, `alarms`.
Програма приймає з'єднання тільки від розширень браузера та сторінок YouTube.

Тести: `node --test tests/extension/*.test.mjs` (логіка) і `node tests/extension/e2e.cjs`
(справжній Chromium + сервер програми; потрібні Playwright і Python із PySide6).
