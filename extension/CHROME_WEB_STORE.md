# Як оновити розширення в Chrome Web Store

Розширення вже опубліковане, тож **нове створювати не треба** — у тому самому записі
завантажується новий пакет. Після перевірки Google усі користувачі отримають оновлення
автоматично (Chrome перевіряє оновлення кожні кілька годин).

## 1. Підготувати архів

```bash
python tools/pack_extension.py
```

З'явиться `dist/VPT_Pad_YouTube_<версія>.zip`. Важливо:

* `manifest.json` має лежати **в корені** архіву (скрипт так і пакує);
* `"version"` у `manifest.json` має бути **більшою** за опубліковану (зараз `2.0.0`;
  для наступних оновлень — `2.0.1`, `2.1.0` тощо). З тією самою версією магазин архів не прийме.

## 2. Завантажити в магазин

1. Відкрийте **Chrome Web Store Developer Dashboard**: https://chrome.google.com/webstore/devconsole
   (увійдіть тим акаунтом, з якого публікували).
2. Оберіть своє розширення (MacroPad YT Control).
3. Вкладка **Package** → **Upload new package** → оберіть zip з кроку 1.
4. Вкладка **Store listing** — за бажанням оновіть опис і скриншоти (текст нижче).
5. Вкладка **Privacy practices** — заповніть пояснення дозволів (текст нижче) і позначте,
   що розширення **не збирає даних користувачів**.
6. **Submit for review**. Перевірка зазвичай триває від кількох годин до кількох днів;
   статус видно в дашборді, лист прийде на пошту акаунта.

## Дозволи — що вписати в «Privacy practices»

**Single purpose (єдине призначення):**
> Керування відтворенням YouTube з фізичного макропада VPT | Pad через локальну програму VPT | Pad.

| Дозвіл | Обґрунтування |
|---|---|
| `scripting` | Виконує команду макропада (пауза, перемотка, гучність, швидкість) у вкладці YouTube через API плеєра сторінки. |
| `storage` | Запам'ятовує, якою вкладкою YouTube керувати (вибір користувача у вікні розширення) — лише до закриття браузера. |
| `alarms` | Раз на 30 секунд перевіряє, чи запущена програма VPT \| Pad, щоб підключитися до неї автоматично. |
| Доступ до `youtube.com`, `m.youtube.com`, `music.youtube.com` | Керування плеєром відбувається лише на сторінках YouTube і YouTube Music. |

**Remote code:** не використовується (увесь код — у пакеті).
**Data usage:** розширення не збирає, не передає і не продає жодних даних. З'єднання
встановлюється лише з `ws://localhost:8765` — програмою VPT | Pad на комп'ютері користувача.

## Якщо після оновлення розширення вимкнулось у користувачів

Chrome вимикає оновлене розширення й просить підтвердження, якщо нова версія просить
**ширші дозволи**, ніж стара (наприклад, доступ до сайтів, якого раніше не було).
Розширення 2.0 просить доступ до `www.youtube.com`, `m.youtube.com` і `music.youtube.com`.
Якщо стара версія мала доступ лише до `www.youtube.com`, користувачі побачать запит
«Нові дозволи» і мають натиснути «Увімкнути». Щоб цього уникнути, перед публікацією порівняйте
`host_permissions` / `content_scripts → matches` у старому `manifest.json` і за потреби
залиште в новому лише ті самі сайти.

## Перевірити локально перед публікацією

`chrome://extensions` → увімкнути **Режим розробника** → **Завантажити розпаковане** →
теку `extension/`. (Опубліковану версію з магазину на час перевірки краще вимкнути, щоб
обидві не керували YouTube одночасно.)
